# Keyword Click A Point

Implementação de keyword para clicar em um ponto específico da tela usando coordenadas absolutas.

## Uso

```robot
Click A Point    x=100    y=200    duration=200
```

## Parâmetros

- `x`: Coordenada X na tela (obrigatório)
- `y`: Coordenada Y na tela (obrigatório)
- `duration`: Duração do clique em milissegundos (opcional, padrão: 100)
